# Single Layer Perceptron Lab - Streamlit

## Run locally

1. Open a terminal in this folder.
2. (Optional) Create and activate a virtual environment.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Start the app:

```bash
streamlit run app.py
```

The app contains four sections: AND/OR/NAND logic gates, XOR convergence experiment,
scholarship eligibility, and candidate selection. Learning rate, maximum epochs,
and random seed can be adjusted from the sidebar.
